서비스: 왜뜨지? (안드로이드 앱과 웹) · 시행일: 2026년 10월 16일

1. 한눈에 보기

왜뜨지?는 회원가입이나 로그인이 없고, 이름·이메일·전화번호·위치 같은 개인정보를 직접 모으지 않아요. 아래 내용은 앱을 쓰는 동안 어떤 정보가 어디에 쓰이는지를 정리한 거예요.

2. 운영자

개인 개발자 (GitHub: dodasifamily) · 문의 이메일: issuewhyhelp@gmail.com

3. 이 기기에만 저장되는 정보

  • 아침 알림을 켰는지, 받을 시간, 알림을 위해 등록해 둔 분야·시간 목록
  • 내가 고른 관심 분야 (밈·신조어, 스포츠 등)
  • 마지막으로 받아 둔 해설 사본 (인터넷이 없을 때 보여주기 위해서예요)
  • '내용이 이상해요'를 누른 해설의 목록 (같은 해설을 또 누르지 않게 하려고요)

이 정보는 운영자에게 전송되지 않으며, 앱을 지우면 함께 사라져요.

4. 인터넷으로 주고받는 정보

  • 해설 내려받기: 최신 해설 파일을 GitHub Pages(dodasifamily.github.io)에서 받아와요. 이때 접속 기록(IP 주소 등)이 GitHub에 남을 수 있어요. GitHub 개인정보 처리방침
  • 글꼴: 화면 글꼴을 Google Fonts에서 받아올 수 있어요. 이때 IP 주소가 Google에 전달될 수 있어요.
  • 영상(YouTube): 일부 해설에는 언론사 기사에 실린 유튜브 영상이 함께 나와요. 해설 화면을 열면 영상 미리보기 그림을 YouTube 서버(i.ytimg.com)에서 받아오고, 이때 IP 주소 등이 Google(YouTube)에 전달될 수 있어요. 영상은 재생 버튼을 눌러야 열려요. 누르면 YouTube 플레이어(youtube-nocookie.com)가 해설 화면 안에서 열리며, 이때 YouTube가 IP 주소, 기기·앱 정보(앱 ID 포함), 시청 정보를 받을 수 있어요. 앱 안에서 재생되지 않는 기기에서는 YouTube 앱이나 브라우저로 열려요. 왜뜨지?는 YouTube API 서비스를 이용하며, 영상을 재생하면 YouTube 서비스 약관이 적용돼요. Google 개인정보처리방침
  • '내용이 이상해요' 신고: 누르면 메일 앱이 열리고, 해설의 ID·제목(키워드)·날짜, 앱 버전·종류(앱/웹)가 미리 적혀요. 직접 '보내기'를 눌러야 문의 이메일로 전달되고, 이때 보내는 분의 이메일 주소가 운영자에게 보여요. 보내기 전에는 아무것도 전송되지 않아요.
  • 출처 링크: 출처 기사를 누르면 해당 언론사 사이트로 이동하고, 그 사이트의 방침을 따라요.
  • 더 찾아보기: 해설 화면 아래의 '유튜브에서 찾기'·'이미지로 찾기' 버튼을 누르면 그 해설의 키워드로 YouTube나 Google 이미지 검색 결과 페이지가 새 창(또는 브라우저)에서 열려요. 누르기 전에는 아무것도 전송되지 않고, 누르면 검색어와 IP 주소 등이 해당 서비스에 전달돼요. 거기에 보이는 영상·이미지는 그 서비스와 올린 사람의 것이고 왜뜨지?와는 관계없어요. Google 개인정보처리방침

5. 광고 (Google AdMob)

안드로이드 앱에는 Google AdMob 광고가 표시돼요. 광고를 보여주고 성과를 재기 위해 Google이 광고 ID, IP 주소, 기기·앱 정보, 광고 상호작용 정보 등을 수집·이용할 수 있어요. 운영자는 이 정보를 받지 않아요.

  • Google이 광고 서비스 이용 시 정보를 사용하는 방법
  • Google 개인정보처리방침
  • 맞춤 광고는 휴대폰의 Google 설정(광고)에서 끄거나 광고 ID를 삭제할 수 있어요.

6. 알림

알림은 앱의 '알림' 화면이나 휴대폰 설정에서 언제든 끌 수 있어요. 앱 버전에 따라 알림 방식이 달라요.

  • 기본 아침 알림: 휴대폰 안에서 예약되는 알림이에요. 이 알림을 위해 서버로 보내는 정보는 없어요.
  • 푸시 알림 (Google Firebase Cloud Messaging): 앱에서 아침 알림을 켜면, 내가 고른 분야와 받을 시간(예: '스포츠', '오전 8시')이 Google의 알림 서버에 '알림 주제'로 등록돼요. 이를 위해 Google이 이 기기의 알림 등록 값, 설치 ID, IP 주소 등 기기·앱 정보를 처리해요. 운영자는 개별 기기를 알아볼 수 있는 값을 받거나 저장하지 않아요. 알림을 켜기 전에는 앱이 기기 등록을 요청하지 않아요. 알림을 끄면 앱이 등록한 주제를 모두 풀고 이 기기의 알림 등록을 지워요(Google 서비스가 나중에 등록 값을 다시 만들 수 있지만, 주제가 없어서 알림은 오지 않아요). 7. AI가 정리한 내용에 대한 안내

해설은 AI가 여러 출처를 확인해 정리한 요약이라서 틀리거나 오래된 내용이 있을 수 있어요. 각 해설 아래에 출처 기사 링크를 함께 적어 두었고, 내용이 이상하면 해설 화면의 '내용이 이상해요'로 알려주세요. 확인 후 고칠게요.
